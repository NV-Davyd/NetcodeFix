# NetcodeFix

Makes other players' cars move closer to where they really are in CarX Drift Racing Online tandem rooms.

- Better prediction through transitions and counter-steers
- Smoother position and rotation between network updates
- Optional in-world overlay that shows sync corrections
- Automatic correction strength, with manual tuning behind an expert toggle

## Install/update

Install through KSL after the mod is linked in the KSL mod registry. Releases
use tags in KSL's required `v*.*.*` format.
